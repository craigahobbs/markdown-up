View Local Markdown Files

To view local Markdown files, use the MarkdownUp backend application from a terminal prompt:

pip install markdown-up
markdown-up

Host Markdown Web Pages

To host a Markdown resource, add the MarkdownUp application HTML stub to the directory containing your Markdown files:

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>MarkdownUp</title>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <link rel="stylesheet" href="https://craigahobbs.github.io/markdown-up/app.css">
        <link rel="preload" href="https://craigahobbs.github.io/markdown-up/bare-script/static/markdown.css" as="style">
        <link rel="modulepreload" href="https://craigahobbs.github.io/markdown-up/lib/appImports.js" as="script">
    </head>
    <script type="module">
        import {MarkdownUp} from 'https://craigahobbs.github.io/markdown-up/lib/appImports.js';
        const app = new MarkdownUp(window);
        app.run();
    </script>
</html>

To test your Markdown page, start a local static web server:

python3 -m http.server

By default, MarkdownUp fetches the "README.md" resource. To change the default resource, update the application stub file, index.html. For example:

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>MarkdownUp</title>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <link rel="stylesheet" href="https://craigahobbs.github.io/markdown-up/app.css">
        <link rel="preload" href="https://craigahobbs.github.io/markdown-up/bare-script/static/markdown.css" as="style">
        <link rel="modulepreload" href="https://craigahobbs.github.io/markdown-up/lib/appImports.js" as="script">
    </head>
    <script type="module">
        import {MarkdownUp} from 'https://craigahobbs.github.io/markdown-up/lib/appImports.js';
        const app = new MarkdownUp(window, {'url': 'other.md'});
        app.run();
    </script>
</html>

To view a different Markdown resource, set the application's "url" hash parameter (i.e., "http://127.0.0.1:8000#url=other.md").

A Markdown resource's scripts run with the page's origin access (e.g., they can fetch same-origin resources and read local storage). For this reason, the "url" hash parameter only allows same-origin resource URLs by default. To change this, set the application's "hashURL" option to one of the following:

  • 'sameOrigin' - only same-origin resource URLs are allowed (the default)

  • 'any' - any resource URL is allowed. Only use this on an origin where there is nothing to protect - the option applies to the page, but a script's access applies to the page's entire origin.

  • 'none' - the "url" hash parameter is not allowed

const app = new MarkdownUp(window, {'hashURL': 'none'});

MarkdownUp Applications

MarkdownUp applications are Markdown files that contain code. Add a markdown-script fenced code block of BareScript to any Markdown file, and when MarkdownUp renders the file, it runs the script and renders its output in place of the code block. You can learn more from the MarkdownUp backend application's README.

Read Aloud

MarkdownUp reads pages aloud with PicoVox speech synthesis, which runs entirely in the browser. To read the page aloud, click "Read aloud" in the MarkdownUp menu in the upper-right of the page. The voice playback bar appears at the bottom of the window, with play/pause, rewind, skip back and forward by section (the page's top-level headers), voice, and speaking rate controls. Code blocks, images, and controls are not read. PicoVox speaks English text, and it is loaded when it is first used.

MarkdownUp applications read their own Markdown text aloud with the voiceSpeak, voiceSetText, voiceState, and voiceClose functions. An application positions the voice playback bar by rendering an element with the ID "markdownUpVoice" - the bar is rendered in that element.

Applications also say lines of text aloud with the voiceSay function - each in a voice and a speaking style, over any other lines, with no voice playback bar (for example, a film's dialogue). voiceLoad loads the speech synthesizer ahead of the first line, and voiceReady tests whether the browser has let the page's audio start (it may not until the user interacts with the page).

Debug Mode

Debug mode logs the script runtime duration and runs the BareScript linter, which performs static code analysis on your code and reports warnings for any issues found.

To turn on debug mode, click "Debug" in the MarkdownUp menu in the upper-right of the page.
